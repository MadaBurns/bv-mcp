### Changed

- The public `tools/list` response is about 10% smaller (109,105 to 98,201 characters of compact JSON), which lowers the context cost for clients that load the full tool list. Tool descriptions are capped at 400 characters and parameter descriptions at 100; the shared `domain`, `force_refresh` and `format` parameters use one short description each. Only description text changed: tool names, argument schemas, output schemas and annotations are the same (SQ-562, SQ-563).
- A new audit, `test/audits/tool-list-weight.audit.test.ts`, pins the total size and both caps so the list cannot regrow unnoticed.
