### Fixed

- WHOIS shim (`bv-whois`): `.eu` and `.be` registrars now resolve. Those registries print the registrar as a block (a bare `Registrar:` line followed by indented `Name:` and `Website:` lines), which the shared parser refused as a registrar name, so every lookup came back as `unrecognised_response`. The shim now reads the first indented `Name:` of that block, as a fallback used only when the shared parser found no registrar; a block with no `Name:` is classified exactly as before. `.eu` and `.be` are not added to any policy-redaction list. The change takes effect with `npm run deploy:whois`; the main Worker is unchanged.
