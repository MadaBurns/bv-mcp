### Fixed

- WHOIS registrar parsing: the `.eu` and `.be` registrar block now resolves in the shared parser (`@blackveil/dns-checks` whois `parse.ts`) instead of a `bv-whois`-local fallback. A bare `Registrar:` line followed by indented `Organization:` or `Name:` lines yields that value (Organization preferred), stopping at a blank or non-indented line; a block with neither still yields no registrar. This supersedes the SQ-446 note that the fix lives only in the shim: because the parser is shared, it also corrects `rdap_lookup` on the main Worker. It takes effect with `npm run deploy:prod` and `npm run deploy:whois`.
