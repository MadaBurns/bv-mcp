### Security

- Hardened the Enterprise Managed Auth (EMA) tenant store before anything consumes it. With `KV_ENVELOPE_KEY` set, an unsealed (plaintext) tenant record, or one whose `tenant_id` does not match the key it was read from, is now treated as absent instead of trusted. `normalizeIssuer` is now idempotent (all trailing slashes collapse), a `jwks_uri` (supplied or discovered) must pass the outbound-URL gate before it is stored, and an issuer index entry whose owning record is missing or unreadable no longer blocks re-registration or deletion. The runbook section on seeding an EMA tenant now spells out how to suspend one. No migration, no new secret, no behavior change for existing clients.
