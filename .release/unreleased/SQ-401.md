### Changed

- `bv-ct-index` sidecar: name lookups now skip runs that cannot hold the domain. Each run carries a per-run key filter (a Bloom filter over name prefixes), checked inside the D1 catalog query, and the catalog finds overlapping runs through a new interval index instead of reading every row of the generation. Migration `0005_runs_key_filter.sql` adds two nullable columns and must be applied to the remote D1 before this code deploys; runs written before it have no filter and are always read until compaction rewrites them. Merge semantics, the 503-on-fault rule and the cursor format are unchanged. The sidecar is still not bound to bv-mcp, so nothing changes for `discover_subdomains` yet.
