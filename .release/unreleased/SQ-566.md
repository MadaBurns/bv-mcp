### Security

- The recon job poll tools (`osint_investigation_status`, `osint_investigation_report`, `scan_buckets_status`, `scan_buckets_findings`) now answer only when an owner record exists and names the caller. A missing record, a failed KV read, an absent KV binding or a missing caller identity gets the same "not owned by this principal" response as an ownership mismatch, so a job id can no longer be polled by a caller who never started it. A start tool that cannot store its owner record now reports a failure instead of returning a job id nobody could poll. Jobs started before this change, and jobs older than the 24 hour owner-record lifetime, can no longer be polled.
