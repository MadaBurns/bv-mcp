### Fixed

- bv-ct-index sidecar: the hourly T1 roll-up cut key-ordered chunks at a fixed input count and skipped chunks whose runs were all key-disjoint (SQ-518). An overlapping pair that straddled a cut was planned by neither chunk, so it waited until the run count shifted, an hour or two. Chunks are now cut only between groups of overlapping runs, so a straddling pair is merged on the tick it appears. A single group over the job limits is still split by key as before.
