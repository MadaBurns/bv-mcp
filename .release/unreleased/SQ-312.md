### Fixed

- `check_lookalikes`: `mailgun.org` is no longer a "disposable MX" HIGH corroborator (#1198). The same product recommends `include:mailgun.org` in `generate_spf_record` and attributes Mailgun as a mainstream DKIM provider, and on a 4.5-year-old candidate with no A record the Mailgun entry was provably the sole cause of a HIGH stamped `confidence: deterministic`. `DISPOSABLE_MX_PROVIDERS` keeps `mailtrap.io` (a sandbox that never delivers) and the throwaway-inbox services; the new `test/audits/disposable-mx-providers.audit.test.ts` pins the list disjoint from `KNOWN_SPF_INCLUDES` (now exported) and the high-confidence DKIM providers so the two cannot drift again.
- `check_lookalikes`: a wildcard-parked lookalike is no longer credited with "web presence" (#1202, #264). Every finding that carried `hasWebContent` now also carries `webPresence: 'content' | 'none' | 'parked' | 'unmeasured'`, `parkingSignals: ('parking_mx' | 'parking_ns' | 'wildcard_a')[]` and `wildcardProbe`. `parked` comes from measured DNS already in hand — an MX or NS host on a parking network (`PARKING_APEXES`, single-sourced in `shared-ns-hosts.ts` and spread into `SHARED_NS_APEXES`; new `isParkingInfraHost()`) — or from one new random-label A query (`_bv-probe-<random>.<candidate>`) issued only for candidates with both an A and a real MX, inside the existing phase-2 pool and deadline, counting as `parked` only when the HEAD probe also answered. A probe that is not issued, fails, times out or is inconclusive is `not_probed`, never a measured absence; `hasWebContent` keeps its exact prior values. Prose now says "Parked (…)" or "Web presence unmeasured (…)" instead of "Has web presence." for those cases, and `describeCorroborators` names the parking signal.

Score impact (operator attention): `check_lookalikes` is `scanIncluded: false`, so `scan_domain` scores and grades are unchanged (`test/scan-domain` green, 93 tests). The STANDALONE `check_lookalikes` result does move: a mail-capable lookalike fronting Mailgun drops HIGH → MEDIUM (false positive removed); a mail-capable lookalike on parking infrastructure (parking MX/NS, or wildcard zone with an answering page) rises MEDIUM → HIGH (`webPresence === 'parked'` corroborates exactly as "no web content" does; the web-only tier is unchanged). `scoring-version.ts` has treated `check_lookalikes` as score-bearing before, so a `SCORING_MODEL_VERSION` entry at release is the operator's call. Residuals noted on the ticket: `computeSameEntityCandidates` ranks without the parked reading (ordering only); a host that answers DNS but refuses the HEAD probe still reads "Has web presence."; `dnsowl.com` stays in the parking set per the existing classification although it is also NameSilo's default nameserver.
