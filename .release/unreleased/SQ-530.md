### Changed

- bv-ct-index sidecar: the tailer now queues name rows without `key` and `apex`, and sibling rows without `key`. The T0 indexer has derived and checked these fields since SQ-528. Messages are cut on the smaller queued form, so the same rows fit in fewer 64 KB queue units (a measured 34–38% fewer billed queue operations; #1341). Dedup inside the tailer still uses the full rows. This is deploy 2 of 2, and it needs the SQ-528 indexer to be live first (live since 2026-11-01).
