### Changed

- `scripts/access-log/sql/0002_drop_unused_indexes.sql` (operator-applied, idempotent): drops the `country`, `domain` and `ip_masked` indexes on `mcp_access_log`, which no query uses. Each logged call writes 3 index entries instead of 6, on insert and again on the retention delete.
- `ANALYTICS_ROLLUP_INTERNAL` now reaches the internal door (`/internal/tools/{call,batch}`), the only source of `source = 'internal'` rows, so the existing default-off rollup can actually take effect. Behaviour is unchanged while the flag is unset.
- The 15-minute `mcp_access_rollup` provisioning probe runs only when `ANALYTICS_ROLLUP_INTERNAL=true`. With the flag unset it no longer pages about a table nothing writes to, and no longer pays for its 24-hour `mcp_access_log` count each tick.
