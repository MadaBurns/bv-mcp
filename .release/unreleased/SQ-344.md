### Added

- `bv-ct-index` sidecar: the query API behind bv-mcp's `BV_CERTSTREAM` routes (`/enumerate`, `/sans`, `/cert-meta`), read from the run index with 500-name pages, an additive `coverage` object (`historyWindow: 'forward-from'`) and cursor pagination on `/enumerate`. Bearer `CT_INDEX_ADMIN_KEY`, constant-time compare, 401 when unset; any reader fault, a 1500 ms budget overrun or a never-populated index answers 503, never an empty 200. The sidecar is not deployed yet, so nothing changes for `discover_subdomains` until the operator wires the binding.
