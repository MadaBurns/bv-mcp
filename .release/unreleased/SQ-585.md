bump: patch

### Fixed

- `osint_investigate_*_start` and `scan_buckets_start` retry the ownership-record write once before failing, so a single transient KV error no longer discards an upstream job that was already created (its id was never returned).
- A `deep_infrastructure` start whose remembered-target write fails (after one retry) now flags it with `ctTargetNotRemembered: true` on the start result, instead of silently losing the report's CT-discovery composition.
- The "not owned" refusal from `osint_investigation_status`, `osint_investigation_report`, `scan_buckets_status` and `scan_buckets_findings` is marked `partial`, so a transient owner-record read failure is no longer served from the 15s/30s poll cache.

### Release boundaries

- No scoring, tier, grade or `TOOL_DEFS` change.
