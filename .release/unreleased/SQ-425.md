### Added

- `scripts/verify-ema.sh` (`npm run check:ema -- [--base <url>] [--assertion <file>]`): operator-run live post-deploy check for Enterprise Managed Auth. It verifies the AS metadata (jwt-bearer grant, id-jag profile, CIMD, `none`, S256), both protected-resource metadata paths, the 401 lazy-auth challenge on a paid-only `tools/call`, and that `/oauth/token` answers a junk jwt-bearer assertion with `invalid_grant`. `--assertion` exchanges a real ID-JAG and prints only the token length. `--self-test` runs offline.
