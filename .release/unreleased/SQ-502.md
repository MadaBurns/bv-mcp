### Fixed

- `check_realtime_threat_feed` no longer reports a clean "no threat-intelligence match" when the recon backend answers 404. The backend has no threat-intel lookup route, so every lookup was 404ing, and a fabricated benign result hid that. It now returns an inconclusive result (`checkStatus: error`). The 404 is recorded as a degradation (see SQ-514 for its `binding_route_absent` kind). The recon enrichment in `cymru_asn`, `check_lookalikes` and `check_fast_flux` already added nothing on a 404; only its telemetry changes.
