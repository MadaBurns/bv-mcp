### Fixed

- `check_realtime_threat_feed` and the threat-intel enrichment in `cymru_asn`, `check_lookalikes` and `check_fast_flux` no longer report a clean "no threat-intelligence match" when the recon backend answers 404. The backend has no threat-intel lookup route, so every lookup was 404ing, and a fabricated benign result hid that. A 404 is now recorded as a `binding_5xx` degradation. `check_realtime_threat_feed` returns an inconclusive result (`checkStatus: error`), and the three enrichments add nothing.
