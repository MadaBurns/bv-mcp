### Added

- `bv-ct-index` sidecar: `npm -w packages/bv-ct-index run test:coverage` now writes a real coverage report (a text summary and `coverage/lcov.info`, gitignored). It uses the Istanbul provider (`@vitest/coverage-istanbul`, pinned to the installed Vitest 4.1.12), because `@cloudflare/vitest-plugin` only wires V8 coverage for Vitest 5 and later. The plain `test` script is unchanged and no threshold fails the build. A tracked `.claude/quality-gate/crap.json` lets the CRAP gate measure the package from that same report. Test-tooling only; nothing changes at runtime.
