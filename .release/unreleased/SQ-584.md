### Fixed

- `brand_audit_single` and `brand_audit_batch_start` no longer reach tiered discovery for callers below partner tier when `discovery_mode` is omitted and the operator default `BRAND_AUDIT_DISCOVERY_MODE_DEFAULT=tiered` is set. The tier gate now applies to the effective mode: an omitted argument from a lower tier is downgraded to `classic` (so the call keeps working, and the cache key and queued message carry the mode that actually runs), while an explicit `discovery_mode: 'tiered'` from a lower tier is still refused with the existing error.
