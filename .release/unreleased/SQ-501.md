### Changed

- `deploy:prod` and `deploy:prod:staged` now run `check:tenant-schema` (after config injection, before shipping) and fail closed on tenant/registry D1 schema drift or an unreachable live database.
- A tenant monitoring cycle whose reconcile or alert step is still failing a week after it started is now stamped `abandoned_retry_budget` with one operator alert, instead of re-reading its tenant D1 every 15-minute tick forever.

### Fixed

- The tenant drizzle migration journal now has the missing entry for `0002_findings_scan_id_index`.
