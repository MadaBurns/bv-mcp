### Fixed

- `check_resolver_consistency`: a unanimous answer is called `CONSISTENT` only when at least `CONSISTENCY_QUORUM` (3) of the 4 configured resolvers responded (#1199). Below quorum the record type is `INCOMPLETE` (`low`) and the detail names the count and the unreachable resolvers; divergent answers from 2+ responders (`SPLIT_HORIZON` / `SUSPICIOUS`) are unchanged, since quorum guards only the clean claim. Every finding now carries fan-out coverage (`resolversQueried`, `respondedCount`, `unreachableResolvers`, `quorum`, `quorumMet`), the overall-timeout path names late resolvers instead of `unknown`, the full format prints `answered N/M`, and a result with any below-quorum type is `partial` so a degraded fan-out is not cached for the TTL.

Score impact: `resolver_consistency` is an intelligence-only category (not in the scan score). Direct callers that previously saw `CONSISTENT` / 100 from 2-of-4 agreeing resolvers now see `INCOMPLETE` (`low`).
