### Added

- CI now fails a pull request that changes `@blackveil/dns-checks` shipping inputs while the package version still names an existing `dns-checks-v<version>` tag whose contents differ, so a version can no longer drift from the code it identifies before deploy time. Internal tooling only; no runtime behaviour change.
