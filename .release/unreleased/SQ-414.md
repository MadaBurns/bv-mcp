### Added

- OAuth: `src/oauth/jwks.ts`, an RS256/ES256 JWS verifier that checks a compact JWS against a JSON Web Key Set, plus a cached JWKS fetch over `safeFetch` (600s cache in `SESSION_STORE`, 5s timeout, 64KB body cap, no redirects, failures never cached, a forced refetch at most once per 60s per URI). Groundwork for Enterprise Managed Auth (US-14). Nothing calls it yet, so runtime behaviour does not change.
