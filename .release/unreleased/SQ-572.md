### Changed

- The "What the hosted server logs about you" section of the client setup guide now separates the aggregate analytics events (which carry only a non-cryptographic domain fingerprint) from the operator access log (which stores the scanned domain in plaintext next to a truncated credential hash), and says plainly that unauthenticated rate-limit counters use the client IP in short-lived keys. It states the retention default, the optional archive, and what the erase path covers.
- New `docs/integrator-guide.md` covers version stamps, partial scans, batch and asynchronous jobs, quotas, authority to scan, and error handling. The README, the support page and the client setup guide link to it, and the README and support page link the public terms of service (the support page also links the status page).
- The operator runbook's rollback section now covers Durable Object state, points to the staged deploy scripts, and lists the stores that have no documented backup.
